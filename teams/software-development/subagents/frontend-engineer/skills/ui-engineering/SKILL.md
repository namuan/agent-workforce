# UI engineering

- Reuse established components and state patterns where they exist.
- Treat loading, empty, error, keyboard, and screen-reader states as part of the feature.
- Keep visual and interaction changes scoped to the requested behavior.
- Verify with the available typecheck, test, or lint command.

# Testing

- Test observable behavior rather than private implementation details.
- Cover the happy path, the changed edge case, and failure behavior when relevant.
- Mock network or irreversible dependencies at their boundary.
- Keep fixtures small and deterministic.
- State what the tests do not prove.

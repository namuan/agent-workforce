# Implementation planning

- Read the relevant files before naming a change.
- Separate observed facts from assumptions and questions.
- Keep the plan ordered, small, and tied to explicit acceptance criteria.
- Name the checks that would verify each behavior.
- Flag migrations, security boundaries, compatibility changes, and missing tests.
